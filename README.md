# Present Simple Negative ม.1 · Krathong Negatives

เกมวอร์มอัพนำเข้าสู่บทเรียน Present Simple Negative สำหรับนักเรียนชั้นมัธยมศึกษาปีที่ 1 ธีมลอยกระทง

## เนื้อหา

- **ด่านที่ 1 เลือกคำตอบ** 10 ข้อ เลือก do not / does not / don't / doesn't ให้ตรงกับประธาน
- **ด่านที่ 2 เรียงประโยค** 10 ข้อ ลากคำมาเรียงเป็นประโยคปฏิเสธ มีเสียงอ่านประโยคเมื่อเรียงถูก
- แบ่งระดับความยาก: ข้อ 1-3 พื้นฐาน, ข้อ 4-6 กลาง, ข้อ 7-10 ท้าทาย
- ไม่มีจับเวลาและไม่มีอันดับ ตอบผิดได้คำใบ้และลองใหม่ได้
- ปุ่ม "เฉลยสำหรับครู" ในหน้าเกม แสดงเฉลยและเหตุผลของทุกข้อ

## วิธีใช้

เปิดไฟล์ `index.html` ในเบราว์เซอร์ได้เลย ไม่ต้องติดตั้งอะไร

ถ้าต้องการให้นักเรียนเปิดผ่านลิงก์ ให้เปิด GitHub Pages ที่ Settings > Pages แล้วเลือก branch `main` โฟลเดอร์ root

## หมายเหตุ

- เสียงอ่านประโยคใช้เสียงภาษาอังกฤษของอุปกรณ์ที่เล่น ควรทดสอบก่อนใช้สอน
- ฟอนต์ Mali และ Mitr โหลดจาก Google Fonts ต้องต่ออินเทอร์เน็ตจึงจะแสดงตามแบบ
